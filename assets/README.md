# Assets

Images used by the demonstration scenes, the example document and the tests.

Illustrations created or modified by the project owner; permission to use and redistribute them in this plugin, its examples, its screenshots and its releases is confirmed by the owner. The files carry no embedded metadata.

| File | Use |
|---|---|
| `img/background.png` | Demonstration illustration of `examples/perspective_calibration_demo.tscn` |
| `img/background_template.png` | Background of the village example (`examples/village/`) and of the end-to-end scenario in `tests/e2e/` |
| `img/foreground_template.png` | Foreground (transparent PNG), the fountain of the village example and of the end-to-end scenario |
| `screenshots/dock_*.png`, `screenshots/occlusion_*.png` | README screenshots, rendered from the plugin itself with the village example by `tests/render_check/readme_shots.ps1` |
| `screenshots/editor_action_zones_window.png`, `screenshots/game_*.png` | Captured from the real Godot 4.7.1 editor and from the running integration example (`examples/integration/`), cropped to the plugin and game windows |
| `screenshots/perspective_demo.png` | Earlier screenshot of the perspective demo scene |

The addon-only package (`illustrated_walkmesh_editor-<version>.zip`) contains none of these images.
