# Village example

A finished IWE document on the village illustration: four walkable zones (a yard, a crossroads, a bridge and a patch that overlaps two of them), two cutouts for the fountain and a bench, two height references with the camera fitted to them, and the fountain as a foreground picture that the character walks behind and in front of.

## Open it

1. Copy `examples/village/` into a Godot project that has the plugin enabled.
2. In the IWE dock, click `Open` and choose `village.tres`.
3. Open the Test tab, turn on `Test walk` and click the preview: the character goes behind the fountain when it stands farther from the camera than the fountain's base, and in front when nearer.
4. `Export perspective scene` writes the playable stage.

The pictures sit in `assets/` beside the document, so the folder can be moved.

## Rebuild it

`build_village_example.gd` authors the document from an empty one with the helpers of the end-to-end scenario (`tests/e2e/village_scenario.gd`). From the repository root:

```
Godot --headless --path . -s examples/village/build_village_example.gd
```

The two images are AI-generated by the author and free to use (see [`assets/README.md`](../../assets/README.md)).
